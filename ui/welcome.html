AgentFeeda news reader and protocol, with a local model behind it

It needs a model to read with.

Everything AgentFeed does — filing, abstracts, judging what belongs in a topic, answering questions — runs on an open-weight model on your own machine or on a server you point it at. Nothing leaves the machine otherwise.

Looking for a model server… Checking Ollama, LM Studio, llama.cpp, vLLM and NIM on their usual ports.

1 · Run one here

Easiest. Install Ollama, pull a model, and this page will notice on its own.

…
ollama pull qwen3:8b
ollama pull nomic-embed-text

Already have LM Studio? Load a model and start its server (the ↔ tab). Same thing, it is found automatically.

2 · Or point it at a server

Anything that speaks the OpenAI-compatible API: a bigger machine on your network, an NVIDIA NIM container, a hosted endpoint.

— or — open it anyway (reading works, nothing new gets filed)

Which model? A MoE like qwen3:30b-a3b reads at 30B quality on a laptop with 32 GB; qwen3:8b fits 16 GB. Set a 32k context — OLLAMA_CONTEXT_LENGTH=32768 — or whole articles are silently cut.
